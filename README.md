## About Me

I'm a computer science master's student interested in turning AI research into reliable, reusable software.

My current interests sit at the intersection of **perception, language models, and agentic systems**:

- **Computer Vision:** industrial defect detection, object detection, instance segmentation, multi-scale inference, and image processing.
- **LLM & Agents:** Transformer fundamentals, LLM applications, retrieval-augmented generation (RAG), MCP, and multi-agent workflows.
- **AI Engineering:** Python tooling, reproducible experiments, API integration, testing, and maintainable software.

I value clear problem definitions, reproducible results, readable code, and practical engineering.

## What I'm Working On

- 🔬 **Computer Vision research** — exploring YOLO-based detection and segmentation for high-resolution industrial images, including multi-scale and adaptive-tile inference.
- 🧠 **LLM foundations and applications** — learning model architecture, inference workflows, and practical LLM integration.
- 🤖 **Agent systems** — exploring RAG, MCP tool integration, workflow orchestration, and multi-agent collaboration.
- 🛠️ **Python engineering** — improving project structure, testing, documentation, and reusable developer tools.

> Some research work involves private or externally owned data. Only code, datasets, and results that are authorized for public release will be published here.
